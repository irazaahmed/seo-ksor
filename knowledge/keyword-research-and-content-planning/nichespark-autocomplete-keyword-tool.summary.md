NicheSpark is a free Chrome extension by Cybrum Solutions that automates the
Google Instant (autocomplete) keyword method. You create a project from a
seed keyword, pick a method (A to Z, prefix, suffix or template), and it
types each query into Google one at a time, saves every suggestion with its
source query, merges duplicates and skips your own search history.

- Install from the Chrome Web Store; no account; data stays in the browser.
- Each query is marked Done, Empty or Failed; it stops for CAPTCHA or consent
  pages and never bypasses them.
- Filter, copy, export to CSV, and back up or restore a project as JSON.
- It finds phrasing and themes, not search volume: check volume separately.
