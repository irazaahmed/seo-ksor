## AI fundamentals

- **Generative AI:** AI that **generates** something.
- **LLM:** Large Language Model.
- **Automation:** you **automate** the system, deciding what it should do
  and how it should do each thing.
- **AI Agents:** you tell the AI the **result** you want. How it should
  happen, the AI **plans** itself and does that work itself.
- **Vibe Coding:** getting anything built by telling the AI your
  **requirements**.[^ai-agents-class-05]

## Tools and workflow

- **IDE:** where you can read code, see code and see the output. For
  example: **Cursor**, **VS Code**, etc.
- **Modes:** Cursor, or a coding environment, has multiple modes: **plan
  mode**, **debug mode**, **multitask mode**, **Ask Mode**, etc.
- **Agent Instructions:** project rules for coding
  agents.[^ai-agents-class-05]

## Product planning

- **User journey:** the complete path on a website, from arriving to
  exit.
- **Website vs web application:** a **website** has only content pages,
  but a **web application** is interactive software. A web application has
  **2 way interaction**.
- **DBMS:** Database management system.
- **Primary key:** a unique identifier for a database.
- **API:** a contract enabling systems to communicate.[^ai-agents-class-05]
