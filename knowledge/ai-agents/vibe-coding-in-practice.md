## Run the project on localhost

- Whatever project you have built, have the **AI run it on localhost**
  too. Take the app being built last time, for example, and run it today
  to see it. Tell the AI to run it. Whatever **bugs** or issues come up
  while it runs, the AI will fix them itself.
- While building an app or project, you run it on **localhost** and look
  at it. Wherever changes are needed, you keep making them right
  there.[^ai-agents-class-06]

## Write a good PRD at the start

If you make a good **PRD** right at the start, the LLM will write good code
and do good work the **first time**. So put in more effort
initially.[^ai-agents-class-06]

## How to start a project

1. Install **Cursor**.
2. Make a **folder** with the name of the app you are building.
3. Open **Cursor** in that folder.
4. Open the **chat** option and get the AI to start the
   work.[^ai-agents-class-06]

## Which framework for which app

- **Web apps** are built on **Next.js**.
- **Mobile apps** are built on **React Native**.
- With **React Native**, both **Android** apps and **iOS** apps are built
  from one code.[^ai-agents-class-06]

## Use SVG icons

Using **SVG icons** in design is best. They are **vector graphics**. They
can be edited with code: colors, animation, all of it can be done in an SVG
icon through code. Usually the AI uses **image icons**. We have to use SVG
icons, so that we can style them.[^ai-agents-class-06]

## Test as you build

Whatever project you have built, get its **tests** done at the same time.
Tell the AI to test as it goes, and if there is a bug, it will fix
it.[^ai-agents-class-06]

## Selling automation to businesses

1. Do **outreach** to businesses.
2. Understand their **day-to-day workflow**.
3. You will see the **bottleneck**: which of their work can be
   **automated**.
4. Then sell them the **automation**.

Example: a **restaurant** can be built and given an **inventory management
system**.[^ai-agents-class-06]

## What SaaS is

**SaaS** is a product that people purchase and use on a **subscription**
basis.[^ai-agents-class-06]
